This suite offers **2 standalone, independent userscripts** to personalize your AI Chat experience on **ChatGPT**, **Google Gemini**, and **Claude**. You can install and use **either one independently** or **both together**!

---

## 📦 Scripts in This Repository

### 🎨 1. AI UX Customizer Enhanced (`AI-UX-Customizer-Enhanced.user.js`)

A full-featured UI theme customization & navigation engine for **ChatGPT** and **Google Gemini**.

- **🌐 Multilingual (EN / VI)**: Includes a quick language switcher (`🌐 English` / `🌐 Tiếng Việt`) for all menus, tooltips, and settings.
- **✨ Built-in Preset Themes Library**: 6 pre-configured themes (Cyberpunk Neon ⚡, Sakura Blossom 🌸, Emerald Forest 🌲, Sunset Vaporwave 🌅, Deep Space 🌌, Minimalist Slate 📓) applied in 1-click.
- **🎨 Complete UI Control**: Change avatars, display names, standing character images, bubble colors, border radius, padding, page backgrounds, and input box colors.
- **⚡ Automatic Regex Matching**: Switch themes dynamically based on Chat Titles or URL patterns.
- **🚀 Navigation Console & Jump List**: Fixed/floating message toolbar, searchable jump list, and keyboard shortcuts (`Alt+J`, `Alt+N`).

👉 **File**: [`AI-UX-Customizer-Enhanced.user.js`](./AI-UX-Customizer-Enhanced.user.js)

---

### ✏️ 2. Quick Text Buttons (`Quick-Text-Buttons.user.js`)

A 1-click prompt insertion tool for **ChatGPT**, **Google Gemini**, and **Claude**.

- **🌐 Multilingual (EN / VI)**: Quick language toggle (`🌐 English` / `🌐 Tiếng Việt`).
- **⚡ 1-Click Prompt Insertion**: Click any custom button to instantly paste pre-made prompts or code snippets into the chat textarea.
- **📂 Categorized Prompts**: Group your prompts by category (e.g., *Coding*, *Writing*, *Translation*, *General*).
- **⚙️ Easy Management**: Add, edit, remove, or reorganize custom buttons directly from the GUI.

👉 **File**: [`Quick-Text-Buttons.user.js`](./Quick-Text-Buttons.user.js)

## 🛠️ Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) (or Violentmonkey) in your browser.
2. Open Tampermonkey Dashboard -> Go to **Utilities** -> Select **Import from file** or click **Create a new script**.
3. Choose the script you want to install:
   - For UI Customization & Themes: Open [`AI-UX-Customizer-Enhanced.user.js`](./AI-UX-Customizer-Enhanced.user.js)
   - For Quick Prompt Insertion: Open [`Quick-Text-Buttons.user.js`](./Quick-Text-Buttons.user.js)
4. Copy the entire code, paste it into Tampermonkey, and press `Ctrl + S` to save.
